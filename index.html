📦 Products Endpoints

GET
/api/products
List all products in catalog
$ curl http://localhost:8000/api/products
Returns: Array of products
GET
/api/products/:id
Get specific product by ID
$ curl http://localhost:8000/api/products/1
Returns: Single product
POST
/api/products
Create a new product
Required: name, price
Optional: description, stock
{"name":"Laptop","price":999.99,"stock":10,"description":"..."}
PUT
/api/products/:id
Update product details
Fields: name, price, stock, description
{"price":899.99,"stock":15}
DELETE
/api/products/:id
Delete a product
$ curl -X DELETE http://localhost:8000/api/products/1
Returns: Confirmation

🛒 Shopping Cart Endpoints

GET
/api/cart
View all items in cart with totals
$ curl http://localhost:8000/api/cart
Returns: Cart items + total
POST
/api/cart
Add item to shopping cart
Required: product_id, quantity
Validates: Stock availability
{"product_id":1,"quantity":2}
PUT
/api/cart/:id
Update item quantity in cart
Required: quantity
{"quantity":5}
DELETE
/api/cart/:id
Remove item from cart
$ curl -X DELETE http://localhost:8000/api/cart/1
Returns: Confirmation

📋 Orders Endpoints

GET
/api/orders
List all orders
$ curl http://localhost:8000/api/orders
Returns: Array of orders
GET
/api/orders/:id
Get order details with items
$ curl http://localhost:8000/api/orders/1
Returns: Order + line items
POST
/api/orders
Create order from cart
Required: customer_name
Optional: customer_email
Clears cart and updates stock
{"customer_name":"John Doe","customer_email":"john@example.com"}

📊 Data Model

Table Description Purpose
products Product catalog with pricing & stock Store product information and inventory
cart Shopping cart items Temporary storage of items before checkout
orders Customer orders with totals Record completed purchases
order_items Line items per order Store purchased products and quantities

🚀 Quick Start Examples

1. Create a product:
curl -X POST http://localhost:8000/api/products -H "Content-Type: application/json" -d '{"name":"Laptop","price":999.99,"stock":10}'
2. Add to cart:
curl -X POST http://localhost:8000/api/cart -H "Content-Type: application/json" -d '{"product_id":1,"quantity":2}'
3. View cart:
curl http://localhost:8000/api/cart
4. Create order:
curl -X POST http://localhost:8000/api/orders -H "Content-Type: application/json" -d '{"customer_name":"John Doe"}'
